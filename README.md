# EA FC GAMES · Timao FC

Site multipágina de um clube virtual de Pro Clubs. O nome do site é **EA FC
GAMES** e o nome do time é **Timao FC**.

## Como rodar

1. Copie `clube-de-jogos` para `C:\xampp\htdocs\`.
2. Ligue Apache e MySQL no XAMPP.
3. No phpMyAdmin, importe `sql/banco.sql`. Ele já contém os jogadores enviados
   no arquivo `jogadores.sql`.
4. Abra `http://localhost/clube-de-jogos/index.html`.
5. Para administrar o elenco, abra
   `http://localhost/clube-de-jogos/php/jogadores_listar.php`.

## Versionamento

Este projeto utiliza Git para registrar o histórico de alterações.

Foi desenvolvido para a disciplina de Desenvolvimento de Websites (DWS).

A versão original utiliza PHP e MySQL no XAMPP. Para publicar no GitHub Pages, as funcionalidades que dependem do servidor precisam ser adaptadas.Este projeto utiliza Git para registrar o histórico de alterações realizadas durante a disciplina de DWS.
